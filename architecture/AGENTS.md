# PP250 Architecture Agent Instructions

## Closed historical evidence corpus — mandatory constraint

For PP250 architectural reconstruction, treat the currently collected surviving PP250 source material in this repository and material already supplied by the repository owner as the **closed historical evidence corpus** unless the repository owner explicitly introduces a new source.

**Do not tell the repository owner to look for more PP250 documentation, manuals, instruction descriptions, specifications, archives, or missing explanatory text. Do not propose finding an undocumented manual as the next step.** The repository owner has repeatedly stated that the surviving material already supplied is what is available. If further historical documentation existed and were available to him, it would already be part of this investigation.

When the surviving evidence does not explicitly answer a question, the task is **architectural reconstruction from the evidence already held**, not documentary lookup. Apply the root `AGENTS.md` method:

**Observation -> Constraint -> Reconstruction -> Prediction -> Falsification**

A statement that a hypothesis is "testable" must mean testable against an observation already present in the evidence corpus, against internal architectural consistency, against an implementation/experiment, or against an explicitly identified comparison architecture. It must **not** be followed by a suggestion to search for missing PP250 documentation.

It is legitimate to re-read, cross-correlate, or reinterpret material already in the repository. It is also legitimate to examine independently available later/comparison architectures (for example KHH/CLOOMC or CHERI) when the purpose is comparative reasoning. Do not confuse that with expecting new PP250 documentation to resolve a historical gap.

When the corpus cannot discriminate between reconstructions, say **UNKNOWN** or preserve the competing hypotheses. Do not invent a missing source and do not make "find more documentation" the escape route.
