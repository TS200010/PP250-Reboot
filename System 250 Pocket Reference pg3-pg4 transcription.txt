                         INSTRUCTION CODES (Cont'd)

SHIFT:          +VE VALUES SHIFT LEFT
                -VE VALUES SHIFT RIGHT

CORRELATE:      SCANS FROM LEFT TO RIGHT

                RESULT = 0   IF BIT 23 SET
                       = 1   IF BIT 22 SET
                       ETC.
                       = 32  IF NO BITS SET

MULTIPLY:       DOUBLE LENGTH RESULT

                LS HALF IN D REGISTER
                MS HALF IN D + 1 REGISTER

DIVIDE:         DOUBLE LENGTH DIVIDEND

                LS HALF IN D REGISTER (23 BITS)
                MS HALF IN D + 1 REGISTER (24 BITS)

                RESULT IN D REGISTER
                REMAINDER IN D + 1 REGISTER
                INDICATORS SET ON RESULT

MOVE:           E.G. MOVE D2 @ D5

                SOURCE C2
                SOURCE OFFSET D2
                DESTINATION C3
                DESTINATION OFFSET D3
                SUMCHECK D5
                COUNT D0

                OVERFLOW TO BE RESET BEFORE MOVE
                ON EXIT, OVERFLOW SET BY 'STATUS' WIRE
                INDICATOR SET ON COUNT
                IF COUNT NON-ZERO, DEVICE IS 'BUSY'
